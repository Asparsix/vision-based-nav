================================================================================
MEANINGS (SHORT)
================================================================================
Stereo L/R     Two cameras; left RGB used for UNet + RTAB
Depth          Per-pixel distance (metres), not colour
Point cloud    Depth turned into 3D (X,Y,Z) points
Seg UNet       Neural net: each pixel = road/grass/tree/background
VIO / VO       Visual odometry from camera motion
EKF            Fuses wheel + IMU + VO into smooth odometry
RTAB-Map       SLAM: map + localization without GPS
Global planner Finds A→B path on the full map
Controller     Follows path, outputs /cmd_vel


================================================================================
THE PLAN (PHASES)
================================================================================
Phase 0  Baseline
         Gazebo outdoor/courtyard UGV + teleop + camera topics alive

Phase 1  Sensors
         Stereo L/R + mono alias /camera/image_raw + depth + IMU + wheel odom

Phase 2  Perception dataset
         Collect images → auto-label masks → train UNet (Seg UNet)

Phase 3  Live perception
         ROS segmenter + semantic / traversability costmap

Phase 4  Fused odometry (VIO path)
         Wheel + IMU + RGB-D VO → EKF → /odometry/filtered

Phase 5  SLAM (RTAB-Map)
         Feed RGB + depth + filtered odom
         mapping:=true  → build rtabmap.db
         mapping:=false → localize on same DB

Phase 6  Planning & control (Nav2)
         Global planner + controller on fused costmaps → /cmd_vel
         Demo: map once, then navigate A→B


================================================================================
WHAT WE FEED TO RTAB (AND WHY)
================================================================================
  RGB (left)              visual features, place recognition
  Depth                   3D structure / obstacles for the map
  /odometry/filtered      motion prior (better than raw wheel alone)
  IMU                     orientation support

WHY RTAB (not odom-only):
  Odometry drifts. RTAB builds a map, recognizes revisited places
  (loop closure), and keeps global pose consistent for Nav2.
